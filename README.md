# ve-whitepaper

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.22899298.svg)](https://doi.org/10.5281/zenodo.22899298)

**VE (Veritas Enuntiationis)** is a framework for executable truth-value adjudication, featuring:

- **Three-domain separation** — Entity, Symbolic, Observational
- **Anchoring** — Truth requires an entity anchor
- **Anti-circularity** — Self-referential loops are rejected before adjudication
- **Timestamps** — Exist-time and observe-time as distinct conditions
- **Versioning** — Every adjudication is traceable and revisable
